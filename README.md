CurtainCall hires a small, professionally trained crowd to applaud you every time you finish a load of laundry — one sentence, 222 characters, pitching the worst app idea ever pitched for make.fun's "The Worst App Idea Ever Pitched" bounty.

## Run it

```sh
python3 main.py
```

The program writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when that variable is unset).
